## Быстрый старт

1. Скачай [готовый архив](https://github.com/vantaeonx/python-guide-ru/releases/latest/download/python_practice_90_tasks.zip) и распакуй его.
2. В VS Code выбери **Файл → Открыть папку / File → Open Folder** и открой `python_practice`.
3. Открой PDF и нужный файл, например `ex04.py`.
4. Впиши своё имя в `# Автор`, прочитай объяснение и допиши обработку и вывод.
5. Сохрани файл и запусти его в терминале VS Code:

   ```bash
   python3 ex04.py
   ```

   В Windows используй `py ex04.py` или `python ex04.py` — ту команду, которая работает в твоей установке.

Если Python и VS Code ещё не установлены, ниже есть инструкции. Для этих задач дополнительные библиотеки и установка через `pip` не нужны.

Можно также выбрать на GitHub **Code → Download ZIP**, распаковать репозиторий и открыть его корневую папку — ту, где лежат `README.md` и `ex01.py`. Имя папки в этом случае может быть `python-guide-ru-main`; оно не влияет на работу заданий.

## Установка Python

Нужен **Python 3**. Если проверка версии уже работает, повторно устанавливать его не нужно.

### Windows

1. Открой [официальную страницу Python](https://www.python.org/downloads/) и установи **Python Install Manager** для Windows.
2. После установки открой новое окно PowerShell или терминала и установи стандартную версию Python:

   ```powershell
   py install default
   ```

3. Проверь:

   ```powershell
   py --version
   ```

Если у тебя уже установлен Python с прежним установщиком, достаточно проверить `py --version` или `python --version`. Команда `py install` относится к новому Install Manager.

[Официальная инструкция для Windows](https://docs.python.org/3/using/windows.html).

### macOS

1. Скачай установщик Python 3 для macOS с [python.org](https://www.python.org/downloads/).
2. Открой скачанный `.pkg` и пройди установку.
3. Открой новое окно Terminal и проверь:

   ```bash
   python3 --version
   ```

[Официальная инструкция для macOS](https://docs.python.org/3/using/mac.html).

### Ubuntu

Сначала проверь в терминале:

```bash
python3 --version
```

Если команда не найдена, установи Python из пакетов Ubuntu:

```bash
sudo apt update
sudo apt install python3
python3 --version
```

[Официальная инструкция Ubuntu](https://ubuntu.com/developers/docs/howto/python-setup/). Для других дистрибутивов Linux используй их менеджер пакетов.

## Установка и настройка VS Code

1. Скачай [Visual Studio Code](https://code.visualstudio.com/) для своей системы и установи его. В Ubuntu со Snap можно использовать:

   ```bash
   sudo snap install --classic code
   ```

2. Открой раздел **Расширения / Extensions** и установи **Python** от **Microsoft** (`ms-python.python`). Репозиторий также предложит это расширение при открытии папки.
3. Открой папку с заданиями через **File → Open Folder**.
4. Открой любой `.py`-файл. Нажми `Ctrl+Shift+P` (`Cmd+Shift+P` на macOS), найди **Python: Select Interpreter** и выбери установленный Python 3.
5. После сохранения файла нажми кнопку **Run Python File** в правом верхнем углу редактора. Результат появится в терминале.

Расширение Python помогает редактору работать с языком; сам Python устанавливается отдельно. При желании файлы можно запускать терминальной командой и без расширения.

[Официальный гайд по Python в VS Code](https://code.visualstudio.com/docs/python/python-tutorial) · [Установка VS Code в Linux](https://code.visualstudio.com/docs/setup/linux).

## Как устроены файлы

Пример заготовки:

```python
# Автор: ____________________

# Переменные
age = 16
height_cm = 172.0

# Обработка

# Вывод
```

`Traitement` по-русски означает **«Обработка»**. В Python комментарии начинаются с `#`, а `//` обозначает целочисленное деление.

- Начальные значения уже записаны: сначала можно проверить решение на них.
- Если условие просит ввод, затем замени соответствующие значения на `input()`, `int(input())` или `float(input())`.
- Если ввод повторяется в цикле, его нужно написать самостоятельно.
- В заготовках функций стоит `pass`: он ничего не делает и оставляет место для твоего кода.
- В задачах на чтение сначала запиши прогноз комментариями, затем запускай код для проверки.
- Ответы на вопросы записывай в комментариях того же `.py`-файла.
- Если пустая заготовка ничего не выводит, это нормально: раздел вывода ещё не заполнен.

Проверяй не только первый пример, но и остальные случаи из PDF. После решения попробуй объяснить каждую строку своими словами.

## Почему некоторые файлы содержат ошибки

В упражнениях **«Исправить»** ошибки оставлены специально:

| Файл | Что нужно учесть перед запуском |
| --- | --- |
| `ex20.py` | Неверный синтаксис и отступ: сначала исправь их |
| `ex35.py` | Бесконечный цикл: сначала найди причину; остановить запуск можно `Ctrl+C` |
| `ex65.py` | Попытка вычислить среднее пустого списка |
| `ex78.py` | Использование результата функции без `return` в вычислении |

Это часть заданий. Остальные упражнения на исправление тоже нужно проверять по их условиям.

## Если не получается запустить

| Проблема | Что проверить |
| --- | --- |
| `python3`, `python` или `py` не найдены | Проверь установку Python и открой новое окно терминала |
| `can't open file` или файл не найден | Терминал должен быть открыт в папке с нужным `exNN.py` |
| Не видно кнопки запуска | Открой `.py`, установи расширение Python и выбери интерпретатор |
| Появился запрос ввода | Введи значение в терминале и нажми Enter |
| Дробное число не принимается | Вводи точку: `7.5` |
| Ничего не появилось | Проверь, написал ли ты вывод через `print()` |
| Программа не останавливается | Нажми `Ctrl+C` и проверь условие и обновление данных в `while` |
